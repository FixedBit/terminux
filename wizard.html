Pick what you want on your phone. The command on the right updates as you go; copy it and paste it into Termux. Not sure? The Recommended preset is a good start, and you can add more later with terminux add.

This page never asks for keys or passwords. If you chose NetBird, the installer asks for your setup key on the phone, or see how to pass it privately.

After it finishes, open Termux again and run terminux for a menu, or terminux start for the desktop.
