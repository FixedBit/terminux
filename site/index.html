Linux on your phone, from one command.

A full desktop, VS Code, AI coding tools and as many Linux environments as you like, running in Termux on Android. No root.

How it works

  1. Install Termux from F-Droid or GitHub. Not the Play Store version, which is outdated.
  2. Open the wizard and pick your desktop, apps and extras. It writes the install command for you.
  3. Paste the command into Termux. It installs everything, including the Termux:X11 app that shows the desktop. Allow 20–40 minutes.
  4. Reopen Termux and type terminux for a menu, or terminux start for the desktop.

Happy with the defaults?

XFCE desktop, VS Code, Firefox, VLC, Python, and zsh with Oh My Zsh. Paste this into Termux and skip the wizard:

Termux 
~ $ curl -fsSL https://fixedbit.github.io/terminux/install.sh | bash

What you can set up

A desktop
XFCE, LXQt, MATE or KDE Plasma in the Termux:X11 app, GPU-accelerated on Adreno phones.
VS Code
The native build, or Microsoft's own in a Debian environment.
AI tools
Claude Code, Codex CLI, Gemini CLI, OpenCode, GrapeRoot, Aider, Cursor, Ollama and llama.cpp.
Environments
Separate Linux systems for development, gaming or security work, each with your own user.
Phone fixes
Keeps Android from freezing or killing the desktop, fixes Samsung audio, sizes text for high-resolution screens.
NetBird
Put the phone on your private mesh without root. Keys are entered on the phone, never here.
