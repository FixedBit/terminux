Linux on your phone, from one command.

A full desktop, VS Code, AI coding tools and as many Linux environments as you like, running in Termux on Android. No root. Pick what you want below and paste the command into Termux.

  1. Install Termux from F-Droid or GitHub. Not the Play Store version, which is outdated.
  2. Choose what to install below, or start from a preset. Everything can be changed later.
  3. Copy the command and paste it into Termux. It installs the Termux:X11 app for you and takes 20–40 minutes.

This page never asks for keys or passwords. If you chose NetBird, the installer asks for your setup key on the phone, or see how to pass it privately.

After it finishes, open Termux again and run terminux for a menu, or terminux start for the desktop.
